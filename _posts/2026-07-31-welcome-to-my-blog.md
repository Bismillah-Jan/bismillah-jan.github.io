This is the first post on my new site. Each week I plan to write a short update on what I'm building, what I'm learning, and anything interesting I've run into along the way.

A few things you'll find here:

- **Portfolio** — a running list of projects I've built, with links to code and live demos.
- **Weekly posts** — short-form notes, not polished essays. The goal is consistency over perfection.

To add a new post, drop a Markdown file into `_posts/` named `YYYY-MM-DD-title.md` with a `title` and `date` in the front matter — Jekyll takes care of the rest.
