## MS Thesis

**Correlative Machine Learning for Tumor Detection and Classification**
Supervisor: Dr. Fayyaz Ul Amir Afsar Minhas — Pakistan Institute of Engineering and Applied Sciences (PIEAS), 2015–2017

The objective of this research was to classify cancer tumors using machine learning techniques based on skin images and lung computerized tomography data, using correlation filters generated through machine learning.

## BS Final Year Project

**Protein Image Classification using Extended Threshold Adjacency Statistics (ETAS)**
Supervisor: Dr. Muhammad Tahir — FAST National University of Computer and Emerging Sciences, 2011–2015

Developed a feature-extraction algorithm called ETAS for sub-cellular protein image classification, achieving strong performance with SVM-based classification compared with prior methods.
